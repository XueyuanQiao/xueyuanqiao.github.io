> **资深全栈测试架构师 · AI Native Quality Engineer**
>
> 十年深耕，从大搜索、金融级支付到 AI 原生产品，专注于"以研发视角重塑质量底座"。把 **AI 能力作为引擎**、把 **多语言全栈技术** 作为支点、把 **测试架构设计** 作为方法论，构建可演进的企业级质量基础设施。

## 个人总结

### 一、十年全栈质量治理积淀
深耕测试开发与质量工程领域十年，先后历经 **百度大搜索**、**支付宝金融级核心系统**、**AI Phone 前沿产品** 三大量级业务的实战淬炼。覆盖 Web、客户端、服务端、数据链路、算法模型五大战场，形成了完整的 **白盒 / 灰盒 / 黑盒 + 静态 / 动态 / 模糊 / 混沌** 全维度测试方法论体系，能够深度参与并驱动研发全生命周期质量治理。

### 二、跨职能技术架构视野（QA → RD → Test Architect）
具备从 QA 工程师向 RD 成功转型、再回归测试架构的复合背景。能够以 **研发视角重塑质量底座**，从底层架构层面剖析系统风险。主导过亿级 PV / TPS 量级分布式系统的架构重构、数据链路优化与稳定性建设，在架构层面降本增效与故障可观测性建设方面落地多个标杆案例。

### 三、对 AI 的持续学习与实战落地
对我而言，AI 不是一组工具的清单，而是 **一种持续重塑工作方式的学习习惯**。每天保留固定时间跟踪前沿（论文、X、产品发布、源码），并坚持一个朴素的原则——**任何新能力，必须在真实业务里跑通一次，才算"学过"**。

近一年的实践沉淀大致分三层：

- **学习与思考层**：用 **NotebookLM** 把论文、内部文档、长视频沉淀为可对话的知识库，把"读完即忘"的输入变成可复用的研究资产；新模型、新框架发布后，第一时间在小型真实场景里做 A/B 验证，再决定是否纳入生产。
- **研发协同层**：日常以 **Kiro / Cursor / Claude Code / Codex / Antigravity** 等编程 Agent 作为主力副驾，按场景分工——架构演进与多文件重构走 Kiro 的 Spec 流程、复杂调试用 Claude Code 与 Codex 交叉验证、原型探索用 Antigravity 的浏览器化 Agent 完成端到端闭环；这套协同方式让我能在有限时间内推动多个项目并行演进。
- **业务落地层**：基于 **LangChain / LangGraph** 设计多 Agent 协同的测试系统，在 AI Phone 业务里把"用例生成 → 执行 → 评估 → 缺陷归因"做成一条闭环；用 **LLM-as-a-Judge** 替代易碎的硬编码 Diff，让评估随业务语义演进；通过 RAG 把领域知识注入测试助手，使新人 onboarding 与回归分析效率显著提升。

我更看重的不是"用过多少工具"，而是 **是否真的在每个项目里因为 AI 而做出了过去做不到的事**——用更小的团队覆盖更大的质量域、用更短的周期完成更复杂的验证、把原本依赖经验的判断沉淀成可复用的资产。

### 四、金融级高并发稳定性专家
曾担任 **支付宝核心业务 QA Owner**，在国家级战略项目（春晚红包、跨境支付、数字人民币等）的极高合规与资金安全要求下主导质量护航。精通 **全链路压测**、**混沌工程**、**容灾演练**，在高并发、高可用分布式系统的风险防控、应急响应与故障复盘方面具备扎实的实战成果。

### 五、测试架构设计与从 0 到 1 工程赋能
具备较强的技术落地与平台化建设直觉，多次主导从零搭建企业级测试平台——自动化框架、CI/CD 与质量门禁、全链路压测平台、缺陷分析与质量度量数仓——以技术手段解决业务稳定性痛点。坚持通过 Code Review、技术分享与内训体系驱动团队效能跨越式增长，培养多名核心技术骨干。
