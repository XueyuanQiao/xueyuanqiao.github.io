# Xueyuan's Tech Blog

欢迎访问我的技术博客！这是一个具有现代科技感设计的个人博客网站，展示了我对编程和技术的热情。

## 🚀 特色功能

- **现代化UI设计**：采用深色科技风格配色方案，结合渐变色彩和光影效果
- **流畅动画交互**：包含多种动画效果如悬停变换、渐入效果、扫光动画等
- **响应式布局**：适配各种屏幕尺寸，提供一致的用户体验
- **高性能渲染**：优化的CSS和JS，确保快速加载和流畅体验

## 🎨 设计亮点

- 深色主题配合蓝色高亮，营造科技氛围
- 卡片式布局，带悬停提升和发光效果
- 动态网格背景，增强视觉层次
- 流畅的过渡动画和交互动效
- 现代化的排版和间距设计

## 🛠 技术栈

- **框架**：Jekyll 4.3 + minima主题
- **样式**：SCSS + CSS3动画
- **插件**：jekyll-feed, jekyll-sitemap, jekyll-seo-tag
- **特效**：纯CSS3实现的各种动画效果
- **适配**：响应式设计，支持移动端

## 📊 内容涵盖

持续分享编程经验与技术心得，包括但不限于：
- Python开发技巧
- 爬虫技术
- 自动化测试
- 数据库优化
- 前端技术
